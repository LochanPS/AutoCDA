AutoCDA

Verification API

POST a circuit intent, get back a SPICE-verified, buyable design: real component values, the ngspice-measured result, honest error, the netlist, and a bill of materials.

Verified by real ngspice — deterministic, no per-call AI cost

Base URL & auth

All endpoints return JSON and send permissive CORS. Replace the base URL with your deployment host. For local dev it is http://localhost:3002.

BASE=https://api.autocda.example      # your API host
# Authenticate with a key (optional — see tiers below):
#   -H "x-api-key: YOUR_KEY"   or   -H "Authorization: Bearer YOUR_KEY"
No key required to start. Anonymous calls use the free tier. A key raises your rate limit. Keys are issued by the operator (set server-side via API_KEYS); never put a key in client-side code or a URL.

Rate limits & tiers

Free (anonymous)

10 req / min
No key. Limited per IP. Good for trying the API.

Keyed

120 req / min
Send a key. Per-key limit is operator-configurable; higher tiers available.

Every response (except /api/health) carries rate headers:

HeaderMeaning
X-RateLimit-LimitRequests allowed in the current window
X-RateLimit-RemainingRequests left in this window
X-RateLimit-ResetUnix time (s) when the window resets
Retry-AfterSeconds to wait (only on 429)

Check your own usage any time:

curl "$BASE/api/usage" -H "x-api-key: YOUR_KEY"
# { "ok":true, "tier":"keyed", "limit":120, "used":57, "windowRemaining":119 }

Endpoints

Health

GET/api/health

No auth, no rate limit — safe for uptime probes.

curl "$BASE/api/health"
# { "ok":true, "service":"autocda-verify-api", "types":19 }

List circuit types

GET/api/types

The 19 supported circuit types and the target fields each accepts.

curl "$BASE/api/types"
# [ { "id":"rc_lowpass", "name":"RC Low-Pass Filter", "fields":["fc"] },
#   { "id":"sallen_key_lowpass", "name":"Sallen-Key Low-Pass (2nd order)", "fields":["fc"] }, ... ]

Parse a prompt

POST/api/parse

Turn plain English into a structured spec (no design/verify step). Useful to preview how a prompt is understood.

curl "$BASE/api/parse" -H "content-type: application/json" \
  -d '{"prompt":"high-pass filter 6kHz, 2% tolerance on E96"}'
# { "ok":true, "type":"rc_highpass", "targets":{"fc":6000},
#   "constraints":{"tolerance":0.02,"eSeries":"E96"}, "confidence":0.9, "assumed":[] }

Verify a design

POST/api/verify

The main endpoint. Give a prompt, or an explicit { type, targets, constraints?, strategy? }. Returns the chosen components, the ngspice-measured result, honest error vs. target, the netlist, and a BOM.

FieldTypeNotes
promptstringNatural language. Omit if sending type.
typestringA /api/types id.
targetsobjecte.g. { "fc": 1000 }
constraintsobject{ "tolerance":0.05, "eSeries":"E24" } (optional)
strategystring"reasoning" (default) or "grid"
curl "$BASE/api/verify" -H "content-type: application/json" \
  -d '{"prompt":"low-pass filter at 1kHz"}'
# {
#   "ok":true, "type":"rc_lowpass", "name":"RC Low-Pass Filter",
#   "targets":{"fc":1000}, "verified":true,
#   "targetName":"fc", "target":1000, "measured":994.8, "errorPct":0.0052,
#   "converged":true, "iterations":1, "eSeries":"E24", "tolerance":0.05,
#   "components":[ {"ref":"R1","value":"1 kΩ","rawValue":1000,"unit":"Ω"},
#                  {"ref":"C1","value":"159 nF","rawValue":1.59e-7,"unit":"F"} ],
#   "bom":{ "rows":[...], "total":0.XX },
#   "netlist":"* RC Low-Pass ...",
#   "trace":[ ... reasoning-loop steps ... ]
# }

Explicit form:

curl "$BASE/api/verify" -H "content-type: application/json" \
  -d '{"type":"voltage_divider","targets":{"Vin":9,"Vout":3.3},"constraints":{"eSeries":"E96"}}'

Compose a multi-stage circuit

POST/api/compose

Cascade verified stages into one circuit, measured end-to-end.

curl "$BASE/api/compose" -H "content-type: application/json" \
  -d '{"stages":[{"type":"rc_highpass","targets":{"fc":300}},
               {"type":"rc_lowpass","targets":{"fc":3000}}]}'
# { "ok":true, "stages":[...], "predicted":{...}, "measured":{...},
#   "errors":{...}, "components":[...], "bom":{...}, "netlist":"..." }

Errors

Errors are JSON: { "ok":false, "error":"..." }.

StatusWhen
400Invalid JSON, or required field missing
401Unknown API key
413Request body exceeds the size cap (64 KB default)
422Prompt not understood, or spec invalid for the type
429Rate limit exceeded — see Retry-After
500Unexpected server error
